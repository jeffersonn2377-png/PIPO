Short Project Report Preview

1. Executive Summary

This project presents a hardware-accurate software simulator of a Parallel-In Parallel-Out (PIPO) Data Buffer, fulfilling the requirements for EC2201 Digital Systems. The solution simulates N-bit D-flip-flop register operations, timing constraints (setup/hold time, propagation delay), tri-state outputs, and multi-stage FIFO buffer throughput.

2. Digital System Architecture

The core PIPO register consists of N positive edge-triggered D flip-flops sharing a common clock (CLK), clock enable (LOAD), and asynchronous active-low reset (RST_N). Parallel input words D[N-1:0] are sampled on the rising clock edge and output simultaneously as Q[N-1:0].

3. AI & Data Analytics Layer

An IsolationForest model detects timing anomalies ($t_{su} < 1.0\text{ ns}$) and bit flips. Performance analysis demonstrates max bandwidth of $800\text{ Mbps}$ at $100\text{ MHz}$ for 8-bit registers.
